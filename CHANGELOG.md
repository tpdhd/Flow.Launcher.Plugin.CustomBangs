# Changelog

## 0.7.0

- Configurable or empty activator, so bangs work with or without a prefix
- Custom bangs mapping a command to one or more `%s` search URLs
- Search groups that run the same query across several existing shortcuts
- Import and export using the Custom Bang Search version 6 JSON format (version 5 import also supported)
- Native Flow Launcher settings panel with search, edit, multi-select, delete, reset, import, and export
- Project-owned curated starter list, plus an optional ready-made list in `lists/`
